## Setup and Information

Create virtual environment and activate.

`pip install pydriller`

The list of apache repositories I used are in list_of_repos.txt

Script assumes local repos at "./repos"
EG: "./repos/commons-lang/"

Run using `python tdd_miner.py`

Currently generates a .csv with the name "tdd_dataset.csv"

NOTE: Careful on re-runs as old results will be overwritten, if file name is not changed.
